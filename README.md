# dsh-netease-float

[English](README.en.md) | 简体中文

DeepSeek Harness 的网易云音乐**整页播放器**插件：在侧栏点「音乐」打开独立页面，页面内完成播放、看歌词、翻歌单、搜索和登录，不再占用一个悬浮小窗。

> 本项目由 [stardream-1/dsh-netease-float](https://github.com/stardream-1/dsh-netease-float)（MIT）的悬浮小窗版改造而来，保留其壁纸/场景能力，主界面重构为整页布局。

## 项目介绍

DSH 里已有的网易云插件大多是悬浮小窗：只能盯着当前这一首，想看歌单、搜歌、登录还得回宿主界面折腾。这个插件把整套网易云搬进一个独立页面——点侧栏「音乐」打开，正在播放、全屏歌词、我的歌单、歌单详情、搜索都在同一页，顶部一个搜索框，页面内不再造左导航。播放器跟着页面走，换视图不打断播放。

数据直接走网易云 Web 接口（含 eapi 加密的验证码登录），播放地址拿到后会先探测文件头；遇到某些 CDN 节点 403，会自动换节点重试，而不是把错误丢给用户。

## 功能

- **独立音乐页**：侧栏「音乐」入口，点开即全页播放器，不占工作区浮窗
- **正在播放**：封面取主色、标题/歌手分层、进度条（可拖动）、音量、循环三态、随机、上一首/下一首
- **全屏歌词**：点歌词区进入，当前行高亮、前后行渐隐；支持翻译
- **我的歌单**：账号歌单网格，点开看详情、整单入队
- **搜索**：单曲 / 歌单两个 tab，歌单可直接打开
- **歌曲行内菜单**：`⋯` 里「下一首播放」「加到队列」
- **设置**（宿主「设置 → 音乐」）：账号、播放、歌词、外观四组

## 账号与登录

四种方式，都在「设置 → 音乐 → 账号」里：

| 方式 | 说明 |
|---|---|
| 手机验证码 | 手机号 + 短信验证码（eapi 接口），未注册手机号会自动创建账号 |
| 扫码登录 | 网易云 App 扫码；服务端可能返回 8821 拒绝，属平台风控 |
| 粘贴 Cookie | 从浏览器/客户端复制 `MUSIC_U=...; __csrf=...` 粘贴导入 |
| 从本机客户端读取 | 读取本机网易云客户端的登录态（v10 AES-GCM 解密），**只有播放权限，读不到账号资料与完整歌单** |

凭据只写本机 `~/.dsh/netease-float.json`，不上传；退出登录会清掉。

> 免费曲目无需登录即可播放。VIP/付费曲目需要有效的登录态。

## 安装

**插件面板**

1. 克隆仓库到本机任意位置
2. 设置 → 插件 → 添加插件，填该目录
3. 完全退出 DSH 后重新打开

**手动**

`~/.dsh/profiles/desktop/package.json`：

```json
{
  "dependencies": {
    "dsh-netease-float": "file:<插件目录>"
  },
  "dsh": { "profile": { "bundles": [
    "...",
    "dsh-netease-float"
  ] } }
}
```

`file:` 用绝对路径，Windows 下写成 `file:D:/plugins/dsh-netease-float`。改完在该目录执行 `pnpm install`，重启 DSH。

## 常见问题

**点了播放没反应 / 提示无法播放**：先看是否会员曲目（需要登录）；若地址拿到了但 CDN 返回 403，插件会自动换 `m801`/`m701` 等节点重试。

**歌单是空的**：本机客户端登录态只有播放权限，服务端会把它当匿名用户（uid=0）返回空歌单；需要正式登录。

**扫码一直停在「已扫码」**：网易云对扫码登录有风控（8821），换手机验证码或粘贴 Cookie。

**进度条拖不动**：已修复。
